# Movie Roulette

Приложение для выбора фильма с друзьями в Discord: каждый заранее добавляет желаемые фильмы, Миша переносит список в рулетку и крутит на выбывание.

## Запуск

```bash
cd game
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

## Как пользоваться

1. **Желаемые** (вкладка слева) — введите ник и фильмы (по одному на строку). Артём, Джебра и остальные могут добавить свои варианты в любое время.
2. **Экспорт / Импорт** — отправьте JSON в Discord, друг импортирует на своём устройстве.
3. **В рулетку все** — Миша переносит весь список в рулетку одной кнопкой (или по человеку / по фильму).
4. **Рулетка** — предпросмотр крутится, пока добавляются фильмы. Кнопка «Крутить» выбивает выбывающий фильм; последний оставшийся — победитель.
5. Звук рулетки подстраивается под количество фильмов в списке (кнопка «Звук» в сайдбаре).

## Поиск фильмов (необязательно)

Создайте `game/.env.local`:

```
VITE_POISKKINO_TOKEN=ваш_токен
```

Токен: [poiskkino.dev](https://poiskkino.dev). Без токена фильмы можно вводить вручную.

## Сборка

```bash
npm run build
npm run preview
```

Данные хранятся в `localStorage` браузера (желаемые, рулетка, победители).
